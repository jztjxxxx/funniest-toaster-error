An entry for the make.fun bounty [The Funniest Toaster Error Message](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd): one error line a kitchen toaster would show its owner, written out by a small Node program.

## The error message

> Error 404: Bread not found. It went in. It never came out. Please do not open the toaster and ask it questions.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (UTF-8, 111 characters, no trailing newline). Set `MAKEFUN_OUTPUT_DIR` to write somewhere else. Node 22, standard library only, no network.
